숫자를 읽는 방법

원본 행 수는 입력 파일 규모이며, DB 시설 수와 다릅니다.

신규 생성은 DB에 새로 등록한 건수입니다. 실제 신규 개업 수가 아닙니다.

기존 레코드 반영은 동일 식별자를 다시 처리한 횟수로, 중복 행과 값이 같은 행도 포함할 수 있습니다.

삭제 표시 제외는 원본의 삭제 표시 행 수입니다. 실제 비활성화된 DB 시설 수와 다를 수 있습니다.

실행별 건수를 합산해 고유 시설 수로 사용하지 마세요. 성공 상태에서도 개별 행 실패가 있을 수 있습니다. 이 화면은 자동 수집의 정상 작동이나 원본의 최신성을 보증하지 않습니다.
