# 공공시설 데이터 모니터링

관리자로 로그인한 후 `/admin/fitness/datasyncrun/`에 접속합니다.
관리자 메인 화면의 Data sync runs 목록에서도 열 수 있습니다.

- 현재 연결된 DB의 전체·활성·비활성 시설 수와 좌표 보유 활성 시설 수
- 최근 실행 상태와 최근 성공 실행의 생성·기존 반영·제외·행 실패 비중
- 최근 20회 원본 규모와 처리 결과, 개별 실행 상세 링크

새로고침 버튼으로 DB를 다시 조회합니다. 화면 접속으로 다운로드나 적재가 실행되지는 않습니다.
`sync_facilities` 명령이 기록한 `DataSyncRun`을 사용하며, 이력이 없으면 빈 상태를 표시합니다.
이전 `import_facilities` 실행 결과나 문서의 로컬 검증 수치를 임의로 채우지 않습니다.
운영 데이터를 보려면 이 변경을 배포한 운영 서버의 관리자 화면을 이용해야 합니다.

실행 이력은 관리자 화면에서 읽기 전용입니다. staff 로그인과 DataSyncRun 조회 권한이 필요합니다.
DB 모델 변경이나 migration은 없습니다.

## 발표 시 해석

현재 DB 레코드 수와 한 번의 파일 처리 건수는 서로 다릅니다.
신규 생성은 신규 개업 수가 아니며, 기존 반영은 실제 값이 바뀐 고유 시설 수가 아닙니다.
같은 시설을 여러 번 처리할 수 있으므로 실행 건수를 누적해 시설 수라고 표현하지 않습니다.
변경 없음은 처리 생략이며, 성공 상태라도 행 실패 수가 0인지 함께 확인해야 합니다.
마지막 성공 시각은 수집 원본의 공식 갱신 시각이 아닙니다.
